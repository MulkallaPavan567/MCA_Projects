Steps to run:


Requirements

1.Download and Install any local web server such as XAMPP/WAMP.
2.Extract the zip file. 

Installation/Setup

1.Open your XAMPP Control Panel and start the Apache and MySQL.
2. Extract the downloaded source code zip file.
3. Copy the extracted source code folder and paste it into the XAMPP's "htdocs" directory
4. Browse the PHPMyAdmin in a browser. i.e. http://localhost/phpmyadmin
5. Create a new database naming onlinecourse.
6. Import the provided SQL file. The file is known as onlinecourse.sql 
7.Browse the Online Course Registration System in a browser. i.e. http://localhost/onlinecourse2/ and http://localhost/onlinecourse2/admin for the admin side.
